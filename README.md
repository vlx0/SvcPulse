# SvcPulse

**Службы, которые выбиваются.** Автозапуск, но служба стоит. И те, что работают, хотя тип старта — вручную.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 11 — «Фон»** · день 72.

Не ProcWatch: там процессы. Не StartAudit: там ключи Run и папка автозагрузки. Драйверы ядра сюда не входят.

---

## Возможности

- автозапуск и при этом остановлена; службы «по событию» в этот список не попадают
- запущена, тип старта вручную; службы текущего сеанса (`…_65eea7e`) считаются отдельно
- остановка с подтверждением
- RpcSs и такие же без кнопки, даже если Windows формально разрешает STOP
- без прав администратора список виден, остановка нет
- только Win32, без pip

## Установка

```powershell
git clone https://github.com/vlx0/SvcPulse.git
cd SvcPulse
pythonw run_svcpulse.pyw
```

Или `start.bat`.

Нужен Windows 10+ и Python 3.10+. Внешних зависимостей нет.
